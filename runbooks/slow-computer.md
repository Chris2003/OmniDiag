# Slow computer / high resource usage

1. Run the **SlowComputer** workflow and review CPU, memory, and top-process findings.
2. If uptime is high, schedule a restart with the user before deeper work.
3. Review startup items; disable only non-business items with the user's agreement.
4. If the system drive is nearly full, run **Clear Temporary Files** (dry run first).
5. Re-scan and compare (`-CompareWith Last`) to confirm the improvement before closing the ticket.
6. Persistent high usage from a managed agent: escalate to the owning team, do not uninstall it.
